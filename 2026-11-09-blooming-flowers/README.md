# Blooming Flowers 🌸

A "for anushkebi" bouquet in the style of the glowing-flowers trend. It starts with three flowers and keeps blooming from the centre outwards until the wrapped bouquet is full, with petals opening one by one and soft light particles drifting up. Tap to add flowers faster; once it's full, tap to make it bloom again.

- Plain HTML/CSS/JS, no dependencies
- Mobile-first (uses `dvh`, safe-area insets, fewer elements on small screens)
- Smooth on phones: every animation is `transform`/`opacity` only, so it runs on the GPU compositor
- Respects `prefers-reduced-motion`

Open `index.html` in any browser.
